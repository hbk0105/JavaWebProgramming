Java, Spring, 전자정부프레임워크 기반으로 공공기관 교육·정보시스템의 구축과 운영 업무를 수행해 왔습니다. 기존 업무 흐름을 이해하고 기능을 개선하는 일부터 기관 간 데이터 연계, 개발 환경 구성·배포 개선, 공공사업 감리 대응까지 경험했습니다.

현재 국민체육진흥공단 K스포에듀 LMS 유지보수를 담당하며 망 분리, ISMS-P 인증 대응, 웹 접근성 및 보안 취약점 개선 업무를 수행하고 있습니다.

업무 외에는 AI 도구를 학습 보조 수단으로 활용하면서 Spring Boot 기반 개인 프로젝트를 진행하고, 새로운 기술을 직접 실습하며 개발 역량을 넓혀가고 있습니다.
